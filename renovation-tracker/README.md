# 装修家电家具采购清单网页应用

一个简洁美观的装修采购管理工具，帮助你轻松追踪装修过程中的所有采购项目。

## ✨ 功能特点

- 📊 **实时统计面板** - 一目了然查看项目进度、预算使用情况
- 🏷️ **智能分类** - 按大类、状态多维度管理
- 🔍 **强大筛选** - 快速找到需要的项目
- ✏️ **即点即改** - 所有单元格都可直接点击编辑，像Excel一样方便
- 💾 **自动保存** - 数据保存在浏览器本地，不会丢失
- 🎨 **精美界面** - 全蓝色渐变背景、流畅动画、响应式设计
- ✨ **动态特效** - 浮动光效、渐变动画、悬停效果

## 🚀 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 无需安装任何软件或服务器
3. 所有数据自动保存在浏览器本地存储中

## 📱 功能说明

### 核心指标面板
- 总项目数统计
- 已完成项目数
- 比价中/已下单项目数
- 预算合计
- 按优先级分类统计（必买、重要、按需、可延后）

### 筛选功能
- **大类筛选**：系统设备、水处理、网络/智能、灯具照明、五金电气、定制/收纳、家具、家电、洁具、软装、小件/用品、清洁/工具、安全、服务
- **状态筛选**：未开始、已列入预算、比价中、已下单、已买/已完成
- **搜索功能**：支持项目名称、类别、品牌、备注搜索

### 即点即改功能 ⭐
所有单元格都可以直接点击编辑：
- **空间** - 点击后变为文本输入框
- **大类** - 点击后变为文本输入框
- **项目** - 点击后变为文本输入框
- **优先级** - 点击后变为下拉选择框（必买/重要/按需/可延后）
- **状态** - 点击后变为下拉选择框（未开始/已列入预算/比价中/已下单/已买/已完成）
- **预期花费** - 点击后变为数字输入框
- **采购品牌/型号** - 点击后变为文本输入框
- **备注** - 点击后变为文本域（支持多行）

### 编辑体验
- 🖱️ 鼠标悬停显示编辑图标
- ⌨️ 按**回车键**保存（文本域除外）
- 💾 失去焦点时**自动保存**
- ⎋ 按**ESC键**取消编辑
- 🔄 所有修改实时保存到本地存储

### 其他功能
- **优先级排序**：点击表头"优先级"可升序/降序排序
- **添加项目**：点击"+ 添加项目"按钮
- **删除项目**：点击行末的🗑️图标
- **空间汇总**：按空间统计项目数量和预期花费

## 🎨 视觉特效

- **动态渐变背景**：全蓝色主题，背景缓慢流动
- **浮动光效**：三个装饰性光球在页面中缓慢移动
- **卡片动画**：悬停时卡片上浮并显示阴影
- **行动画**：表格行淡入效果
- **按钮特效**：点击按钮时的波纹效果
- **编辑图标脉动**：悬停在可编辑单元格时图标会脉动

## 💡 使用建议

1. **装修前期**：先添加所有必买和重要项目，设置预算
2. **采购过程**：及时更新状态和预期花费
3. **定期检查**：查看预算使用情况，控制总体支出
4. **分阶段管理**：利用大类筛选功能，按类别逐个完成

## 📝 数据说明

- 数据保存在浏览器的 localStorage 中
- 清除浏览器数据会导致信息丢失
- 建议定期截图或导出重要信息
- 更换浏览器或设备需要重新录入

## 🔧 技术栈

- HTML5
- CSS3 (Flexbox, Grid, Animations, Backdrop Filter)
- Vanilla JavaScript
- LocalStorage API
